# Faculty Website 

Вебсайт факультету на Django, що включає модуль програм академічної мобільності та обміну для студентів, а також структурований каталог кафедр і викладацького складу.

---

## Основні можливості

* **Кафедри та викладачі**: Відображення структури факультету, сторінки кафедр та викладацького складу.
* **Програми академічного обміну**: Перегляд актуальних міжнародних програм (`ExchangeProgram`) із деталями про країну, мови, кількість місць та дедлайни.
* **Гнучкі міграції бази даних**: Розділені міграції схеми та даних з підтримкою коректного відкочування (Rollback).
* **Адміністративна панель**: Зручне управління контентом через Django Admin.

---

## Технологічний стек

* **Python** 3.10+
* **Django** 4.2+ / 5.x / 6.x
* **SQLite3** (база даних за замовчуванням)
* **HTML5 / CSS3 / JavaScript**

## ЗАПУСК ПРОЄКТУ

## Клонування репозиторію

git clone https://github.com/khrystyna-skul/foz-website.git
cd foz-website

## Створення та активація віртуального середовища

python -m venv venv
.\venv\Scripts\Activate.ps1

## Встановлення залежностей

pip install django

## Застосування міграцій бази даних

python manage.py migrate

## Створення суперадміна (для доступу до адмінки)

python manage.py createsuperuser

## Запуск локального сервера

python manage.py runserver

## Після запуску вебсайт буде доступний за адресою: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Панель адміністратора: [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
